# Tips and tricks

Det er en god ide at downloade den nyeste [Git for Windows](https://gitforwindows.org/) og køre installationen.

Især synes jeg, at det er praktisk at sætte checkmark ved "Windows Explorer Integration" - "Git Bash here", så får man åbnet Git Bash i den rigtige folder ved at højre klikke i Explorer og vælge kommandoen.

Ellers navigerer man i Git Bash til den rigtige folder med **"cd"** kommandoen,

fx. **"cd /c/users/<windows bruger navn>/source/repos/<solution folder>"**

Man kan også tilføje en alternativ editor i stedet for vim under installationen, og vælge Notepad, eller en anden foretrukken editor. Dette kan også gøres efterfølgende fra Git Bash. Se hvordan [her](https://www.theserverside.com/blog/Coffee-Talk-Java-News-Stories-and-Opinions/How-to-set-Notepad-as-the-default-Git-editor-for-commits-instead-of-Vim).
