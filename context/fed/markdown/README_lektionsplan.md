## 3. Bemærkninger

Lektionsplanen er vejledende. Bemærk at fordelingen af emner på lektionsnumre i planen ikke er helt identisk med den faktiske slide-inddeling i kursusmaterialet: slidesene for React Styling og Vitest ligger begge under L23, Managing application state under L24, og Redux samt Responsive Web Design begge under L26. Planen placerer Styling i lektion 25, Responsive design i lektion 26 og Redux Toolkit i lektion 27.

Eksamen er en 24-timers hjemmeopgave efterfulgt af en 20 minutters mundtlig prøve. Se opgavesættene i mappen `eksamen/`.
