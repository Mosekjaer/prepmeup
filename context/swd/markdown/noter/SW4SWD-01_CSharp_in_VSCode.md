## Opsætning i VS Code

- [Get started with C# in VS Code](https://code.visualstudio.com/docs/csharp/get-started)
- [Project management](https://code.visualstudio.com/docs/csharp/project-management)
- [Testing](https://code.visualstudio.com/docs/csharp/testing) — ikke strengt nødvendigt for SW4SWD, men der refereres til det undervejs

Bemærk at øvelsesteksterne er skrevet med Visual Studio 2022 for øje ("Add a new C# class library project to the solution"). I VS Code svarer det til `dotnet new classlib` plus `dotnet sln add`.

## Valgfri C#-introduktion

Tidligere hold har efterspurgt en mere basal C#-introduktion. Den anbefalede vej er de første tre videoer i Microsofts *Programming in C# Jump Start* — knap tre timer i alt:

1. Object Oriented Programming, Managed Languages and C#
2. Constructing Complex Types — Object Interfaces and Inheritance
3. Controlling Programmatic Flow — Manipulating Types and Strings

Video 2 er den direkte relevante for uge 00-øvelserne om interfaces.
