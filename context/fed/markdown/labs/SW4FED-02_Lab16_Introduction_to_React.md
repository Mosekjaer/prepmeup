## Step 1

Scaffold a new React project with Vite and give it the name `tictactoe`.

## Step 2

Follow the official "Tutorial: Intro to React" found here: <https://react.dev/learn/tutorial-tic-tac-toe>

BUT you should put the code for the components in separate files. And you should modify the `App` component to show the `Game` component that shows the `Board` component. Follow the guide until you reach "Adding Time Travel".
