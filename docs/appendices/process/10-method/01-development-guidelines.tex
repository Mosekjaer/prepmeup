\section{Conventional branching- and commit strategy}

\textbf{Workflow: Github flow}

No developmnent branch.

We have a main branch and then we create branches that we merge into main branch as we go.


\textbf{Branch naming}

New feature in code: feature/<feature-name>

Writing in docs: docs/<document(s)>

\textbf{How to}

New branch: git switch -c <branch-name>
