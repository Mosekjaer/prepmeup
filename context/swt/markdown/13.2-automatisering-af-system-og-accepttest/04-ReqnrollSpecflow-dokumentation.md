# Reqnroll/Specflow dokumentation

Reqnroll er en extension til Visual Studio, der understøtter skrivning af specifikationer i Gherkin og efterfølgende generering af skeletter til kode, der opsætter og udfører de nødvendige aktiviteter i passende test runner, test framework og isolation frameworks, næsten efter eget valg.

Reqnroll installeres fra Tools/Extensions and Updates... kommandoen i Visual Studio.

Det understøtter sine egne test runnere og Visual Studios Test Runnere.

Som test framework kan man anvende Visual Studios test faciliteter, eller fx. NUnit.

Isolation frameworks skal blot passe med det valgte test framework.

Her er link til [QuickStart](https://docs.reqnroll.net/latest/quickstart/index.html), der anvender Visual Studio test faciliteter (til fx. Assert)

Her er link til fuld [dokumentation](https://docs.reqnroll.net/latest/).
