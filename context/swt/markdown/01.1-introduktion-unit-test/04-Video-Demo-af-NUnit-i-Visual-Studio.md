# Video: Demo af NUnit i Visual Studio

Video nedenfor introducerer NUnit, brugt i Visual Studio. Den forudsætter, at du har installeret Visual Studio og ReSharper

Videoen diskuterer følgende:

- Hvordan oprettes en solution med både applikations- og testprojekter?

- Hvordan bringes testprojektet til at referere til applikationsprojektet, og til NUnit?

- Hvordan skrives en simpel test fixture og test case?

- Hvordan kører jeg unit tests?

- Hvordan kan jeg bruge output fra NUnit til at se, hvor jeg har fejl i min applikationskode?

Som testobjekt benyttes klassen Register, som introduceres på den sidste slide i lektionens præsentation, og som jeg har implementeret og manuelt testet i de forrige videoer.
