## Feltforklaring (fra L3-slides, slide 39–40)

| Felt (dansk) | Felt (slide) | Indhold |
|---|---|---|
| Navn | Name | Name of UC (Start with verb) |
| Mål | Goal | What is achieved by the UC |
| Initiering | Initiation | Actor, System initiation |
| Aktører | Actors and Stakeholders | List of actors; Actor role (type) |
| Antal samtidige forekomster | Number of concurrent occurrences | 1, 2, 10, none |
| Prækondition | Precondition | What must be true on start |
| Postkondition | Postcondition | What is true on completion |
| Hovedscenarie | Main Scenario | Sunshine or Happy path scenario (nummererede trin) |
| Udvidelser/undtagelser | Extension | Alternate flows (fx `[Extension 1a: ...]`) |
| Datavariationsliste | Data Variations List | e.g. Data Formats — technical variations in how data is defined |

Slide-skabelonen har desuden feltet **References** (Other use cases referenced), som ikke er med i docx-skabelonen.

Udfyldt eksempel: "Sæt alarm" i `use-cases-funktionelle-krav.md` (slide 41).
