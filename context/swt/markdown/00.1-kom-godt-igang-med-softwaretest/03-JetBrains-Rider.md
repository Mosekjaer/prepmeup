# JetBrains Rider

Som alternativ til Visual Studio, kan du installer Rider fra Jetbrains gratis. Det virker også på MAC. Rider kan downloades gratis fra Jetbrains, hvis du registrerer dig som studerende: [https://www.jetbrains.com/student/](https://www.jetbrains.com/student/)
