## 1. Værktøjer

Der findes mere end 20 GAI-værktøjer til programmører. I dette kursus fokuseres på GitHub Copilot med Visual Studio Code (VS Code).

Copilot kan også bruges med andre udviklingsværktøjer som Visual Studio og JetBrains Rider.

## 2. Hvad kan GAI gøre for mig?

- Lave requirement specification
- Lave software design / software architecture
- Lave projektstrukturen
- Skrive kode
- Dokumentere kode
- Skrive testkode
- Hjælpe med coding infrastructure og managing deployments

Forbeholdet fra slidesene: ChatGPT og Copilot kan give forslag og rådgivning — de producerer ikke bare et perfekt system, der passer til dine behov.

## 3. Copilot med Visual Studio Code

GitHub Copilot giver forslag til talrige sprog og en bred vifte af frameworks, men fungerer især godt for Python, JavaScript, TypeScript, Ruby, Go, C# og C++.

GitHub Copilot kan også assistere med query generation til databaser.

## 4. Installation af Copilot-extension

Copilot kræver et GitHub subscription. AU-ansatte og -studerende kan få en gratis GitHub-konto og en gratis version af Copilot via https://github.com/education

Fremgangsmåden:

1. Åbn VS Code.
2. Klik på Extensions-fanen i venstre side af VS Code.
3. Skriv "copilot" i søgefeltet. Når du klikker på GitHub Copilot-søgeresultatet, dukker flere detaljer op i højre side af VS Code.
4. Install.
5. Når du har klikket på knappen, spørger VS Code om tilladelse til at logge ind på GitHub. Klik "Allow".
6. Din default browser åbner automatisk og redirecter til GitHub. Du møder en OAuth-skærm, der beder om tilladelse til at lade Copilot-extensionen se din e-mailadresse. Hvis du er tryg ved det, vælg "Authorize Visual Studio Code". Det afslutter installationen af Copilot-extensionen i VS Code.
7. Install.

## 5. Copilot settings

Dine personlige settings for GitHub Copilot inkluderer en option for enten at tillade eller blokere code completion-forslag, der matcher publicly available code.

## 6. Copilot Chat

Copilot Chat kan bruges ligesom ChatGPT — med den fordel, at du udnytter ChatGPT v. 4.0.

## 7. Copilot Ghost Text

Når du skriver kode i editoren, viser Copilot forslag, som du kan acceptere ved at trykke Tab. Feature'en kan slås fra, hvis du finder den irriterende — mere støj end værdi.

Hvis den foreslåede kode ikke er, som du vil have den, kan du bede om alternativer ved at trykke Ctrl + Enter.
