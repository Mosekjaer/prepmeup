# Gherkin i VS Code

Hvis man benytter VS Code skal man installere Reqnroll Nuget pakken og evt et Reqnroll plugin VS Code som hjælper med at skrive tests mm. Desuden skal man tilføje nogle resourcer til sin .csproj.

På [gitlab.au.dk/au-ece-swt/swt-student](https://gitlab.au.dk/au-ece-swt/swt-student/-/tree/main/dotnet/scripts?ref_type=heads) kan du finde et script (create-reqnroll-project.sh) til at oprette et Reqnroll Gherkin test projekt i en eksisterende solution.

Til test af om ens setup virker, kan man prøve denne clone denne [QuickStart](https://github.com/reqnroll/Quickstart/tree/main/ReqnrollQuickstart.Specs) bemærk at løsningen er i "completed" branchen.
