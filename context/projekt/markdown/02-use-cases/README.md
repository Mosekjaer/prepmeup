# 02 — Use Cases (L3–L4)

Lektion 3 (og 4) i SWISE-01 Indledende System Engineering (undervist som del af SW4PRJ4-02 Projekt 4, efterår 2026). Lektionen dækker funktionelle krav specificeret med use cases: aktører, system boundary, use case-diagrammer, brief og fully dressed use cases, guidelines, samt include/extends/generalization som ekstra-emne.
