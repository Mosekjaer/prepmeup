# Læsning

Forståelsen af begreberne integration og integrationstest har ændret sig meget siden introduktionen af vandfaldsmodellen og V-modellen.

Hos Martin Fowler kan vi endnu engang finde en skarp analyse af tingenes tilstand, hvor der med Integrationstest mentes een ting i "gamle dage" og nogle helt andre ting i disse agile tider, især hvor der arbejdes med delsystemer i store systemer.

[https://martinfowler.com/bliki/IntegrationTest.html](https://martinfowler.com/bliki/IntegrationTest.html)

Læs Binder Ch. 13, pp. 627-642, 649-678, vedhæftet her:
