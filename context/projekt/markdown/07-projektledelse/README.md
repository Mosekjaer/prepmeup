## (optional) Øvelser

### Project Planning – WBS og ETC af 2. semester project

- WBS – "Break down" jeres 2.semester project i mindre opgaver (smaller tasks) og ETC – estimer tiden for hver opgave, bruges O (optimistic), N (normal), P (pessimistic) estimeringer.
- Hvor mange tasks efter Work Breakdown Structure?
- Prøve at oprette to kategorier:
  - en med en 14-ugers plan for projektet
  - en anden: tager jeres arkitektur, f.eks. BDD, hvor mange blokke I har? Estimér udviklingstiden (ETC) for hver blok
- Hvordan kommer de frem til "Estimate Time to Complete?"

PERT-formlen fra slides: ETC = (P + 4·N + O) / 6.
