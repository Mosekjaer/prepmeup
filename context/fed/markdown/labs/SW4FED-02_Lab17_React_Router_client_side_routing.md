## Part 1 – Client side routing

In this exercise you shall extend your app from exercise 16 with client side routing.

Install React Router and then add a navbar to the project. The program should start on a "home" page, which just contains a welcome note. The navbar has links to the "Home" page, a page with the game, and a page with a scoreboard (just a heading, as no score is implemented).

Use `<NavLink>` and add style to show which route is active.

Add a **Page not found** page for unknown routes.

## Part 2 – Time travel

Follow the guide [Tutorial: Tic-Tac-Toe – React](https://react.dev/learn/tutorial-tic-tac-toe#adding-time-travel) to add time travel to the app.
