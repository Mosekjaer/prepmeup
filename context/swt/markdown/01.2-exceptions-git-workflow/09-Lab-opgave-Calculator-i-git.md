# Lab-opgave: Calculator i git

[Git Basics - Exercise.pdf](50-Git-Basics---Exercise.md)

For at indøve udvikling med versionsstyring på git repository serveren, kan I fortsætte med at arbejde på Calculator-klassen.

I kan bruge en af jeres egne løsninger, eller den foreslåede løsning (gøres synlig under lektion 01.1 inden i dag).

Den skal nu versionsstyres, lokalt og på git-serveren.

Der er givet en række forslag til udvidelser. Fordel arbejdet mellem jer i de nye grupper, og eksperimenter med, hvordan det er at arbejde parallelt med et centralt repository som samlingspunkt.

For Windows, bemærk at der kan genereres ssl keys med ssl-keygen i PowerShell. Læg mærke til hvor den lægger nøglerne. Det er indholdet af .pub filen som skal kopieres til Gitlab. Hvis Visual Studio kommer med en pop-up (old school udseende) med tekst á la "does not recognize connection to ..gitlab.au.dk" når I cloner, så skal I bare skrive "yes" i tekstfeltet. (Det er den sammen prompt som kommer når man fra en terminal forbinder via ssh første gang, hvor den spørger om man vil godkende host'en, bare i en pop-up!)

P.S. Benyt "Internal" og ikke "Public" når I opretter repos.
