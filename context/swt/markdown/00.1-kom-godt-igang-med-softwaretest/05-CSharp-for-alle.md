# C# for alle

Blandt kursets moduler på Brightspace findes punktet "C# materiale", som man kan bruges til at sætte sig ind i C# hvis man ikke har prøvet det før, eller få opfrisket nogle ting. Emnerne Exceptions og Events kan også findes uddybet her. Den er altid til rådighed, og finder I nogle nye emner, så sætter vi dem også der.
