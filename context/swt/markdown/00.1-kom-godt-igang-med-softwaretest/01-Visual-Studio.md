# Visual Studio

Du skal bruge seneste version af Visual Studio, men kan nøjes med community Edition. Har du en gammel installation af Visual Studio, skal du køre Visual Studio Installer fra Startmenuen, og opdatere til nyeste version. De pakker og komponenter, der skal bruges, er minimum workload ".Net desktop development" og "Git for Windows".
